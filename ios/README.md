# Poku Expenses (iOS)

SwiftUI + SwiftData + CloudKit port of the expense tracker. iPhone only, iOS 17+.

The Xcode project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen)
from `project.yml` and is git-ignored. Never edit or commit `PokuExpenses.xcodeproj`.

## Generate

```sh
cd ios && xcodegen generate
open PokuExpenses.xcodeproj
```

## Test

```sh
./ios/scripts/test.sh                 # unit tests (scheme PokuExpenses)
IOS_SIM="iPhone 17 Pro" ./ios/scripts/test.sh   # another simulator
```
